# posesim

Simulated interactive sound sculpture: 3 virtual cameras → CPU 2D pose per camera → fusion to 3D → proximity/gestures → cohesive stereo music. Public, Apache-2.0. Overview and status in `README.md`; plan in `PLAN.md`, `SLICES.md`, `docs/adr/`, `QUESTIONS.md`. Trust the code over the docs, and fix the docs when they disagree.

## Commands
- `make help` lists targets. `make setup`, `make dev`, `make check` (lint + fast tests + asset licence check; the pre-push hook runs it), `make hooks` once per clone.
- `uv run python scripts/run_scenario.py [--dump-frames]` runs the whole pipeline headless and checks V1 targets; `scripts/analyze_run.py runs/<id>` re-scores a dumped run.
- Tracked on Pandan board MP3D: `pandan board use 50` first (no default board; the pin lapses after 12 h idle). Refer to cards as `MP3D-N`.

## Layout
- `app/` three.js + TS (sim, dashboard, proximity, sculptures; gestures and audio planned). `python/posesim/` camera-node, fusion, contracts. `config/` geometry and thresholds, `calibration/` generated by `scripts/make_calibration.py`.
- Room frame: metres, Z up, +Y front. Skeleton COCO-17. MPJPE uses joints 5–16 only.
- Three.js layers: 0 default, 1 dashboard-only overlays, 2 walls (sensor cameras only). Overlays must stay off layer 0 or they appear in camera images and confuse the detector.

## Conventions
- Branch per slice/card, PR only, CI green before merge. `v3` is stacked on `v1`: retarget its PR to `main` once `v1` merges.
- Fast tests need no models, network or Docker. Heavy ones carry the `integration` marker (`make test-integration`).
- Every bug gets a failing test first. Tests assert observable behaviour.
- New asset or model: add a row to `ASSETS.md` with licence. AGPL/GPL/non-commercial is excluded (ADR-0006).
- Thresholds and geometry live in `config/`, not in code.
- Avatar-specific code (`BONES`, `resolveSides()` in `app/src/sim.ts`) must be re-verified with `analyze_run.py` after any avatar swap: as-is MPJPE must beat the L/R-swapped one. See `docs/avatar-handoff.md`.
- Don't use `pkill -f` from the agent shell; it kills the shell itself.
